Newly-added source code in blueMSX+ falls into three groups:

  1. Third-party sources imported as-is (each keeps its own license):

       Src/SoundChips/NukedOPLL/          GPLv2-or-later  (Nuke.YKT; see LICENSE)
       Src/SoundChips/Emu2413/            MIT             (Mitsutaka Okazaki; see LICENSE)
       Src/SoundChips/Emu8950/            MIT             (Mitsutaka Okazaki; see LICENSE)
       Src/SoundChips/OpenMsxY8950Latest/ GPLv2-or-later  (openMSX; reference only, ported into OpenMsxY8950Latest*.cpp/.h)

  2. Files newly written for this fork that derive from blueMSX / openMSX
     GPL-licensed sources, or extend a GPL-licensed base class / interface,
     or wrap a GPL-licensed third-party import: licensed under
     GPL-2.0-or-later (the majority of the added code).

  3. Files newly written for this fork that are truly independent
     implementations (no derivation from GPL-licensed sources, no
     extension of GPL-licensed base classes): licensed under the
     3-Clause BSD License (SPDX: BSD-3-Clause).

The per-file header of each source file is the authoritative statement
of its license.  Always consult the header when in doubt, and when
adding new files to the fork.

"BSD style".  In practice the majority of blueMSX-developed .c/.h files
carry a GPLv2-or-later header; the per-file header is authoritative.

blueMSX was originally derived from fMSX but now it is free from all
fMSX source. All source used in blueMSX is either under BSD license,
GPL or freeware.

Most files are developed within the blueMSX project but some have their
origin from other sources. All blueMSX developed code is released under
a BSD style license but some of the other code is released under other
license. Most notable are source from:

- openMSX    released under GPL license

Technical information needed to develop blueMSX has sometimes been found
in the source code and documentation of other emulators. These emulators
are:

- openMSX
- BRMSX
- RuMSX
- RedMSX
- MESS
- fMSX-SDL  
- no$msx
