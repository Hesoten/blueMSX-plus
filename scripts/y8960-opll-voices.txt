# Preset voices of the Y8960 cartridge's OPLLEX
#
# make-y8960-opll-voices.py builds
# blueMSX/ReleaseFiles/Machines/Shared Roms/y8960_opll_voices.bin from this
# file.
#
# Four banks, in the order the OPLLEX's bank registers number them. Each bank
# lists voices 1-15 and then the three rhythm entries. A line is one voice:
# the eight bytes registers 00h-07h take for the user voice. Voice 0, the user
# voice, has no preset and is not listed.
#
# The melodic voices are from "Copyright free OPLL(x) ROM patches" by David
# Viens and Hubert Lamontagne, licensed CC BY-SA (no version is given):
#   https://github.com/plgDavid/misc/wiki/Copyright-free-OPLL(x)-ROM-patches
# They were guessed by ear and are not the chips' ROM contents. This file is
# under that license, not under the GPL that covers the rest of blueMSX+.
#
# The rhythm entries are not on that page. They are the values in ymfm's
# YM2413 table, the same in all four banks, and equal NukedOPLL's.
